TestController Configuration Utility

Generate settingsGPIB.txt and settingsLoad.txt for TestController

TestController Multi-Instrument Setup Guidance

• Separate Adapters Mode (Recommended Default): Configuration files are auto-generated with each instrument assigned its own Prologix Ethernet adapter ID (A, B, C...) pointing to 127.0.0.1:1234. This prevents TestController's internal Java single-socket thread lock contention on startup.

• Single Adapter Option: Uncheck "Separate Adapter IDs" below if you prefer to group all instruments under a single GPIB controller ID (e.g., ID A).

• File Destination Directory: Downloaded settingsGPIB.txt and settingsLoad.txt files should be placed directly into TestController's Settings directory (typically located at Documents\TestController\Settings or TestController\Settings).
